# 🧠 MindGraph Notepad

## 📌 Overview

MindGraph Notepad is a **desktop-based note-taking and knowledge management system** built using JavaFX.  
It helps users create, organize, and connect notes using keywords and a graph-based structure for better learning and revision.

The system combines:
- Note-taking
- Knowledge graph navigation
- Study planning
- Revision tracking

---

## 💡 Key Features

### 📝 Note Management
- Create, update, and store notes
- Each note includes metadata (title, keywords, difficulty, timestamps)
- Notes stored using **XML (content)** and **SQLite (metadata)**

---

### 🔗 Knowledge Graph
- Automatically links notes using keywords
- Related notes are highlighted and connected
- Enables semantic navigation between ideas

---

### 📊 Study Modes

#### 1. Study Path Mode (Auto Learning)
- Automatically generates study sequence
- Uses graph relationships and difficulty scoring
- Ensures logical learning order

#### 2. Study Plan Mode (Manual Control)
- Users create custom study plans
- Add, remove, reorder notes
- Saved for future sessions

#### 3. Revision Mode (Reinforcement)
- Queue-based revision system
- Helps users revise previously studied notes
- Supports spaced learning

---

### 🔄 Backtracking System
- Tracks navigation history between notes
- Allows users to return to previous notes
- Works across all study modes

---

## ⚙️ Technologies Used

- JavaFX (Desktop UI)
- SQLite (Metadata storage)
- XML (Note content storage)
- Java Collections (Graph, Queue, Stack, LinkedList)
- Custom Keyword Extraction System

---

## 🧠 System Highlights

- Keyword-based graph linking
- Automatic keyword extraction
- Study progress tracking
- Session history management
- Persistent storage for all modes

---

## 🔁 Workflow

1. Create notes with keywords and metadata  
2. System builds a knowledge graph automatically  
3. Choose study mode:
   - Study Path (auto sequence)
   - Study Plan (manual sequence)
   - Revision Mode (review queue)  
4. Navigate through linked notes  
5. Use backtracking to explore and return  

---

## 🎯 Purpose

To improve learning efficiency by combining:
- Structured note organization  
- Intelligent linking of concepts  
- Adaptive study modes  
- Revision-based learning
